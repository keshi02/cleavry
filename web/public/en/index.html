FAQ

Is it really free?
Yes. Forever. The site has no ads or trackers. There is no paid tier today; if a Pro tier ships in the future, it will add features on top of the free tier (which will keep working as-is).
Where does my image go?
Nowhere. All processing — including the AI inference — happens on your own device. The site has no upload endpoint; it can't receive your image even if it tried.
Why is the first AI run slow?
The model file (~470MB) downloads on first use, then caches in your browser. Subsequent runs are instant.
Which browsers work?
AI background removal needs WebGPU — Chrome, Edge, or Firefox latest. Safari can use the manual editing features but not the AI step (yet).
Can I use this commercially?
Yes. The output is yours. The source code is MIT-licensed. Just respect the original images' rights.
How can I support the developer?
The project is one person's labor of love. Buy me a coffee if Cleavry saved you time.
